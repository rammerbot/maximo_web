# Inversiones Maximiliano 2024

Landing page estática para venta de repuestos y accesorios para motos.

## Estructura
- index.html
- css/style.css
- js/script.js
- images/logo-maximiliano-2024.jpeg

## Publicación con Nginx
Copiar el contenido de esta carpeta al directorio configurado para el sitio, por ejemplo:
`/var/www/maximiliano2024`

Luego configurar el server block de Nginx para apuntar a esa carpeta.
